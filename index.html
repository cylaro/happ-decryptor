Как панель считает устройства и как пользоваться инструментом.How the panel counts devices and how to use the tool.

01

Как панель считает устройстваHow the panel counts devices

Панель (например, Remnawave) считает уникальные значения заголовка x-hwid. Это значение формирует клиентское приложение — Happ, v2RayTun и другие — при каждой загрузке подписки. Два телефона с одинаковым x-hwid для панели неотличимы: они считаются одним устройством. Заголовок отправляют: Happ, v2RayTun, Koala Clash, FlClashX, Prizrak-Box, Throne, Shadowrocket, Karing, Clash Mi, Incy, RenoarX, DeskBox, Passwall-OpenWRT (у части приложений HWID по умолчанию выключен — включите в настройках).The panel (for example, Remnawave) counts unique x-hwid header values. The client app — Happ, v2RayTun and others — produces this value on every subscription load. Two phones presenting the same x-hwid are indistinguishable to the panel: they count as one device. Apps sending the header: Happ, v2RayTun, Koala Clash, FlClashX, Prizrak-Box, Throne, Shadowrocket, Karing, Clash Mi, Incy, RenoarX, DeskBox, Passwall-OpenWRT (some ship HWID disabled by default — enable it in settings).

02

Добавляем устройства: одна идентичность для всехAdding devices: one identity for all

  1. На вкладке «Запрос» задайте идентичность: HWID (10–64 символа, буквы/цифры), User-Agent и модель. Поля сохраняются автоматически.On the Request tab set the identity: HWID (10–64 characters, letters/digits), User-Agent and model. The fields are saved automatically.
  2. Нажмите «Отправить запрос» — панель зарегистрирует эту идентичность и вернёт содержимое подписки.Press «Send request» — the panel registers this identity and returns the subscription content.
  3. На остальных устройствах укажите тот же HWID в настройках клиента, если приложение поддерживает ручной ввод, — все они будут считаться одним устройством. В редакторе кнопка «hwid → в ссылку» дополнительно вшивает HWID в саму ссылку: приложение добавит её только на устройстве с этим HWID.On your other devices enter the same HWID in the client settings where manual input is supported — all of them count as one device. In the editor, «hwid → into link» additionally embeds the HWID into the link itself: the app adds it only on a device with that HWID.

Если клиент не позволяет ввести HWID вручную, он продолжит отправлять свой собственный — и займёт отдельный слот.If a client does not allow manual HWID input, it keeps sending its own value and occupies a separate slot.

03

Если достигнут лимитWhen the limit is reached

Каждый новый уникальный HWID занимает слот. Когда слоты закончились, панель отклоняет новые идентификаторы: ответ приходит с заголовком x-hwid-max-devices-reached: true (часто с пустым телом). Это решение сервера — обойти его со стороны клиента нельзя. Варианты: удалить неиспользуемое устройство в панели, попросить владельца поднять лимит или отключить ограничение для пользователя. Использование подписки сверх условий тарифа может нарушать правила провайдера.Every new unique HWID takes a slot. Once the slots are gone the panel denies new identities: the response carries x-hwid-max-devices-reached: true (often with an empty body). This is a server-side decision and cannot be bypassed from a client. Options: remove an unused device in the panel, ask the owner to raise the limit, or disable the restriction for the user. Sharing beyond your plan may violate the provider's terms.

05

Ссылки и шифрованиеLinks and encryption

Расшифровка happ://crypt…crypt5 выполняется локально. HTTPS URL можно свободно редактировать. Для v2RayTun есть документированный импорт v2raytun://import/{subscription_link}. Crypt5-ссылку создаёт официальный API crypto.happ.su — URL отправляется туда только после вашего согласия. Base64 и JSON в списке форматов — это кодирование данных, а не конвертер конфигураций.Decryption of happ://crypt…crypt5 runs locally. HTTPS URLs can be edited freely. v2RayTun has a documented import v2raytun://import/{subscription_link}. A crypt5 link is issued by the official crypto.happ.su API — the URL is sent there only with your consent. Base64 and JSON in the format list are data encodings, not configuration converters.

06

ПриватностьPrivacy

Расшифровка, редактирование и генерация ссылок не покидают браузер. Заголовки идентичности хранятся только в вашем браузере и уходят напрямую на сервер вашей подписки при запросе. Ответ ограничен 2 МиБ и 15 секундами; приватные адреса и редиректы отклоняются.Decryption, editing and link generation never leave the browser. Identity headers are stored only in your browser and go directly to your subscription server on request. Responses are capped at 2 MiB and 15 seconds; private addresses and redirects are rejected.
